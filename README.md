
# PHGY311 simulations 

## Currently includes: 
- ### Quantal release simulation based on the binomial distribution
- ### Quantal release simulation based on up to three heterogeneous release sites
- ### Single-channel Monte Carlo model
- ### Leaky Integrate-and-Fire neuron model of short-term plasticity and temporal integration
- ### The Hodgkin-Huxley squid giant axon model of the action potential
- ### Learning with Spike-Timing-Dependent Plasticity (STDP), as described by Song and Abbott (2000,2001)
- ### A content-addressable memory retrieval network as described by John Hopfield
